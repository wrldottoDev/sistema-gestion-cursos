1. Antes de empezar

Esta carpeta contiene una versión inicial del Sistema de Gestión de Cursos. Se recomienda utilizar un navegador moderno y, para desarrollo, Visual Studio Code.

Requisitos básicosGoogle Chrome, Microsoft Edge o Firefox actualizado.
Para ejecutar pruebasNode.js instalado en el equipo.
Archivos principalesindex.html, css/, js/ y pages/.
DatosSe guardan en el almacenamiento del navegador, no en un servidor.

2. Cómo ejecutar la aplicación

  1. Extrae el archivo ZIP en una carpeta de tu computadora.
  2. Abre la carpeta sistema-gestion-cursos-main en Visual Studio Code, o localízala en el explorador de archivos.
  3. Opción rápida: abre index.html en el navegador.
  4. Opción recomendada: en Visual Studio Code instala la extensión Live Server, haz clic derecho en index.html y selecciona Open with Live Server.
  5. Usa el menú de la aplicación para navegar a las pantallas de cursos y usuarios según el rol de la cuenta.
Nota: algunas funciones del navegador, como Web Crypto, pueden requerir un contexto seguro. Si la aplicación falla al abrirse directamente como archivo, ejecútala con Live Server.

El acceso con Google aparece como opción prevista, pero no está habilitado en esta versión.

4. Gestión de usuarios

La sección de usuarios está destinada principalmente al Administrador.

  1. Inicia sesión con la cuenta de Administrador.
  2. Abre Usuarios desde la navegación.
  3. Selecciona Registrar usuario para abrir el formulario.
  4. Completa los campos obligatorios, selecciona el rol y, cuando corresponda, la escuela.
  5. Revisa los mensajes de validación y guarda el formulario.
  6. Para modificar un registro, utiliza la acción de edición disponible en el listado, si aparece para ese registro.

La validación puede revisar el correo institucional, la contraseña y otros datos personales requeridos por el formulario.

5. Gestión de cursos

Consultar cursos

  1. Abre Cursos desde la navegación.
  2. Revisa la información del listado y los filtros disponibles.
  3. El listado del Director está pensado para mostrar los cursos asociados a su escuela.

Crear o editar un curso

  1. Desde el listado, pulsa Nuevo curso si la opción está disponible para tu rol.
  2. Completa primero la escuela, el código y el nombre del curso.
  3. Rellena los demás campos requeridos y revisa los mensajes de validación.
  4. Comprueba los cálculos automáticos, como el total de horas de clase y extra clase.
  5. Guarda los cambios con la acción correspondiente. Para salir sin guardar, usa la opción de cancelar o volver.
Estados previstos: En desarrollo, En producción e Inactivo. El flujo institucional completo de envío a revisión y aprobación todavía no está implementado en su totalidad.

6. Datos y almacenamiento

La aplicación utiliza localStorage para conservar datos en el navegador y sessionStorage para información de sesión. Por eso:

  • Los registros no se sincronizan entre computadoras ni entre distintos navegadores.
  • Limpiar los datos del sitio puede eliminar los registros guardados localmente.
  • La información de demostración puede variar si ya se usó la aplicación en ese navegador.
  • No introduzcas datos personales reales ni información confidencial.

7. Ejecutar las pruebas de validación

Las pruebas incluidas comprueban reglas de validación y algunos cálculos. Abre una terminal en la carpeta raíz del proyecto y ejecuta:

node tests/validacion.test.js

Si todo funciona correctamente, la terminal mostrará un mensaje indicando que las pruebas de validación pasaron. Si el comando no se reconoce, instala Node.js y abre una terminal nueva.

8. Solución de problemas

La página no carga los estilos

Comprueba que no moviste index.html fuera de la carpeta del proyecto y que la carpeta css mantiene su ubicación original.

Los botones o formularios no funcionan

Abre las herramientas de desarrollador del navegador con F12 y revisa la pestaña Console. Verifica que la carpeta js esté completa y que los archivos no hayan sido renombrados.

No aparecen los datos que esperaba

Comprueba que estás usando el mismo navegador y perfil. Los datos se guardan localmente y no se comparten entre dispositivos.

No puedo entrar con Google

El acceso con Google no está habilitado en esta versión. Usa las credenciales de demostración.

9. Límites de esta versión

Este proyecto es un prototipo frontend para desarrollo y demostración. No incluye todavía un backend conectado a MongoDB Atlas, autenticación institucional real, correo de notificaciones ni integración con Power Campus.

Las restricciones de acceso en el navegador no sustituyen permisos verificados en un servidor. Antes de usar el sistema con información institucional, debe implementarse autenticación segura, autorización del lado servidor, almacenamiento centralizado, copias de seguridad y pruebas de seguridad.
